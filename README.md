# Judge

Ответственный: Геннадий Тепляков. Подключается в общий репозиторий `algoduel` как submodule `judge/`.

Judge забирает посылку из очереди, компилирует, проверяет корректность,
проходит лестницу ступеней и возвращает `api.Result`.

## Песочница по слоям

Каждый слой реализует `sandbox.Runner` и проверяется набором вредных решений
(fork-бомба, сеть, чтение `/etc/passwd`, выход за память, бесконечный вывод).

- [x] **1. Basic:** таймаут, пустое окружение, лимит вывода, убийство группы процессов
- [ ] **2. Namespaces:** pid, mount, net, ipc, uts, user
- [ ] **3. cgroups v2:** memory.max, pids.max, cpu.max; пиковая память из memory.peak
- [ ] **4. Файловая система:** минимальный rootfs, pivot_root (через перезапуск judge
      помощником внутри namespaces, как в runc)
- [ ] **5. seccomp:** белый список системных вызовов
- [ ] **6. perf:** счётчик инструкций через perf_event_open (только user mode)
